How to update your menus

01

Prepare your image

Design your menu as an image — JPG or PNG works best. Landscape orientation fills the screen better.

02

Name it correctly

Save it as menu.jpg (or menu.png — update the filename in index.html if so).

03

Upload to GitHub

Go to the correct screen folder in your GitHub repo and replace the existing menu.jpg file.

04

Screens update automatically

Each screen refreshes every 5 minutes. No need to touch the TVs.
